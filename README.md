# Meme Wizard

Meme generator with customisable styles and sharing.

## Features

- Image upload and gallery
- Pricing and payments
- Supabase back-end

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Supabase

## Getting Started

```bash
git clone https://github.com/ghostland-dev/meme-wizard-ai.git
cd meme-wizard-ai
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
